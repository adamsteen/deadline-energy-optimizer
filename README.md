# Deadline Energy Optimizer

Deadline Energy Optimizer (DEO) determines the lowest-cost charging strategy required to achieve a target battery state of charge before a configurable deadline.

The project is specification-first. Production implementation begins only after the relevant requirements, architecture and algorithm specifications have been reviewed and locked.
